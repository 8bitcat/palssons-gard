# Palssons Gård

Familjens farming-RPG — spela direkt: **https://8bitcat.github.io/palssons-gard/**

Co-op för hela familjen: mobiler som handkontroller via QR-kod, tangentbord och gamepads.
Bygg din egen bonde: kille/tjej, hudton, frisyr, hårfärg och kläder.

Grafik: [Farm RPG – Tiny Asset Pack](https://emanuelledev.itch.io/farm-rpg) av **EmanuelleDev**
